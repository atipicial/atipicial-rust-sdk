# Getting Started with Atipicial Rust SDK

The Atipicial Rust SDK provides a comprehensive set of tools for building applications on the Atipicial blockchain ecosystem.

## Installation

Add the Atipicial Rust SDK to your Cargo.toml file:

```toml
[dependencies]
atipicial = "2.1.0"
```

## Basic Usage

Here's a simple example of using the Atipicial Rust SDK to create a wallet:

```rust
use atipicial::prelude::*;

fn main() -> Result<()> {
    // Create a new wallet
    let wallet = Wallet::new();
    
    // Print the wallet address
    println!("New wallet address: {}", wallet.address());
    
    Ok(())
}
```
